# نموذج تقرير حادثة تقنية معلومات — v2.0

تحويل نموذج تقرير الحادثة من صفحة HTML مستقلة (نموذج + تصدير Word فقط) إلى **منصة Apps Script** محمية بحساب الجامعة، مبنية على **SRU Secure Access Kit v1.4**.

## الجديد في v2.0
- **الشعارات الثلاثة** (جامعة سليمان الراجحي، ICTD، ITOC) ظاهرة في الصفحة: شريط الرأس (SRU يمين، ICTD يسار) وشعار ITOC أسفل يسار التذييل.
- **استدعاء تقرير سابق عبر قائمة منسدلة**: كل تقرير محفوظ يظهر في القائمة (الرقم المرجعي — العنوان — التاريخ — الخطورة)، واختياره يعيد تعبئة النموذج بالكامل لمراجعته أو تعديله أو إعادة إصدار مستند Word منه.
- **تفعيل Secure Access Kit**: الدخول محصور بحسابات Google الجامعية (`@sr.edu.sa`)، وبالإضافة لذلك بـ **قائمة مصرّح لهم فقط** (`ACCESS_MODE = 'LIST'`) — غير المدرجين تُعرض لهم صفحة "الوصول مقيّد" وتُسجَّل محاولتهم.
- تصدير Word (.docx) باقٍ كما هو من جهة المستخدم (الاتجاه من اليمين لليسار، الهوية البصرية لـ SRU).

## البنية
```
apps-script/
  Code.gs       ← الإعدادات + التحكم بالدخول + حفظ/قراءة التقارير (Google Sheets)
  Index.html    ← الصفحة الرئيسية (النموذج + القائمة المنسدلة + تصدير Word)
  Logos.html    ← الشعارات الثلاثة مضمّنة Base64 (لا تُعدَّل يدويًا)
  Denied.html   ← صفحة "الوصول مقيّد" / "غير مصرح"
github-landing/
  index.html    ← صفحة تسجيل الدخول المنشورة على GitHub Pages
  assets/       ← نسخ ملفات الشعارات لصفحة GitHub
```

| الورقة | الغرض |

## خطوات النشر (~15 دقيقة)
1. **فتح المحرر:** افتح جدول "سجل تقارير الحوادث - ICTD" ← Extensions ▸ Apps Script.
2. **لصق الملفات:** أنشئ/الصق `Code.gs`، `Index`، `Logos`، `Denied` بنفس المحتوى هنا (الإعدادات معبّأة مسبقًا لهذه المنصة — لا حاجة لتعديل CONFIG إلا إذا رغبت).
3. **إعداد قائمة الدخول:** شغّل الدالة `setupAccessList` مرة واحدة من المحرر (▶). ستُنشئ تبويب `AllowedUsers` وتضيف تلقائيًا: حسابك كمالك + فريق ICTD الافتراضي (13 حسابًا). عدّل القائمة لاحقًا من الشيت مباشرة.
4. **النشر:** Deploy ▸ New deployment ▸ Web app
   - Execute as: **Me**
   - Who has access: **Anyone within Sulaiman Al Rajhi University**
   - انسخ رابط الـ Web App (`.../exec`).
5. **صفحة الدخول:** أنشئ مستودع GitHub (مثلاً `ictsru/IncidentReport`)، ارفع محتوى `github-landing/`، الصق رابط الخطوة 4 في `WEB_APP_URL` داخل `index.html`، فعّل GitHub Pages.
6. **الاختبار:**
   - حسابك الجامعي ← يدخل مباشرة ✓
   - حساب جامعي آخر غير مدرج في `AllowedUsers` ← صفحة "الوصول مقيّد" ✓
   - حساب Gmail شخصي ← صفحة "الدخول لمنسوبي الجامعة فقط" ✓
7. **الربط:** أضف رابط صفحة GitHub إلى فهرس ITOC (ورقة Links).

## ملاحظات
- "Execute as: Me" يتيح للصفحة قراءة/كتابة الشيت الخاص بك دون مشاركته مع أحد.
- حذف صف من `AllowedUsers` أو إلغاء تفعيله (`active` = false) يوقف وصول صاحبه خلال دقيقتين (`ACCESS_CACHE_SECONDS`).
- `OWNER_EMAILS` (بريدك) له صلاحية دخول دائمة حتى لو حُذف من القائمة بالخطأ.
- تصدير Word يتم بالكامل من المتصفح (لا يحتاج اتصال الخادم)، لذا يعمل فورًا حتى بعد تحميل تقرير من القائمة المنسدلة.
